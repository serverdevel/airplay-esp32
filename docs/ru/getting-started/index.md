# Начало работы

Чтобы с нуля собрать AirPlay-приёмник, понадобится около получаса и четыре шага. Большую часть времени займёт прошивка.

```mermaid
flowchart LR
    A["1. Что купить<br/><small>две платы, около $10</small>"]
    B["2. Сборка<br/><small>несложная пайка</small>"]
    C["3. Прошивка<br/><small>прямо из браузера</small>"]
    D["4. Первый запуск<br/><small>подключение к сети настройки</small>"]
    E(["Музыка играет"])

    A --> B --> C --> D --> E

    classDef done stroke:#26a69a,stroke-width:2px
    class E done
```

1. **[Что купить](shopping-list.md)** — две платы и штыревая гребёнка, всего около $10
2. **[Сборка](assembly.md)** — припаиваем ЦАП непосредственно под ESP32
3. **[Установка прошивки](flashing.md)** — из браузера либо с помощью PlatformIO / ESP-IDF
4. **[Первый запуск](first-boot.md)** — подключаем устройство к домашней сети Wi‑Fi

!!! tip "Какую именно плату купить?"

    Покупайте **ESP32-S3 N16R8**: 16 МБ flash и 8 МБ octal PSRAM. Только эта
    конфигурация рассчитана на готовую прошивку из релиза. Остальные варианты ESP32
    и готовые аудиоплаты представлены лишь унаследованными, непроверенными профилями.
