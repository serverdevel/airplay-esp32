# Первый запуск

При первом запуске устройство ещё не знает данных вашей сети Wi‑Fi, поэтому создаёт
собственную точку доступа и портал настройки.

1. **Подайте питание на плату** через USB-C.
2. На телефоне или ноутбуке подключитесь к сети Wi‑Fi **`ESP32-AirPlay-Setup`**.
3. Портал настройки должен открыться автоматически. Если этого не произошло, перейдите по адресу **`192.168.4.1`**.
4. Задайте имя устройства, например «Кухня».
5. Выберите домашнюю сеть Wi‑Fi и введите пароль.
6. Устройство перезагрузится и подключится к выбранной сети.
7. Откройте музыкальное приложение, нажмите значок AirPlay и выберите устройство.

Готово. Настройки хранятся в NVS и сохраняются после перезагрузки и обновления прошивки.

!!! tip "Если не удалось подключиться к Wi‑Fi"

    После нескольких неудачных попыток устройство автоматически возвращается в режим
    настройки. Снова подключитесь к `ESP32-AirPlay-Setup` и исправьте параметры сети.

<a id="the-web-interface"></a>
## Веб-интерфейс

После подключения устройства к домашней сети его веб-интерфейс можно открыть в
браузере. IP-адрес указан в списке подключённых клиентов роутера и в последовательном
журнале устройства.

| Страница | Назначение |
| --- | --- |
| `/` | Настройка и управление: имя устройства, Wi‑Fi и громкость |
| `/logs` | Просмотр журнала в реальном времени |
| `/bq` | Посекционный биквадратный эквалайзер и кроссоверы на платах с TAS5825M |

Через тот же интерфейс устанавливаются [обновления прошивки по OTA](../reference/ota.md),
поэтому USB потребуется только для первой прошивки.

<a id="something-not-working"></a>
## Если что-то не работает

Если сеть настройки не появляется, портал сообщает `file not found` или после
подключения нет звука, откройте раздел [«Устранение неполадок»](../troubleshooting.md).
