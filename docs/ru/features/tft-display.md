# ST7789 TFT-дисплей

Цветной IPS-дисплей с диагональю 1,9 дюйма и разрешением 320×170 может отображать метаданные дорожки в полноцветном растровом изображении.
фон с индикатором выполнения и истекшим/оставшимся временем. Использование рендеринга
[LVGL 9](https://lvgl.io/) с `esp_lvgl_port`.

<figure markdown>
  ![Дисплей ST7789, показывающий название трека, исполнителя и индикатор выполнения](../../assets/display_st7789.png){ width="500" }
</figure>

!!! warning "Требуется ESP32-S3 с PSRAM"

    Этот драйвер несовместим с оригинальным ESP32. LVGL 9 плюс звук AirPlay
    конвейер плюс WiFi превышает бюджет внутренней SRAM, а флэш-память Wrover объемом 4 МБ слишком
    небольшой, если учитывать аудиостек, раздел SPIFFS и ресурсы LVGL.

`idf_component.yml` обеспечивает это: LVGL и `esp_lvgl_port` объявляются только как
    зависимости, когда целью является `esp32s3`. Сборки, отличные от S3, не затрагиваются — управляемые
    компоненты никогда не загружаются, а драйвер OLED продолжает работать.

Протестировано на ESP32-S3 N16R8 (флэш-память 16 МБ, PSRAM 8 МБ) с ESP-IDF 5.5.3.

| Дисплей PIN-код | ESP32-S3 GPIO | Функция |
| --- | --- | --- |
| СКЛ/КЛК | 18 | Часы SPI |
| ПДД/МОСИ | 17 | Данные SPI |

| РЭС/РСТ | 21 | Сбросить |

<a id="enabling"></a>
## Включение

Дисплей **отключен по умолчанию**.

=== "конфигурация меню"

    ```bash
    idf.py menuconfig
    # AirPlay Receiver → Display Configuration → Enable display
    # Select driver: ST7789 TFT (320×170 landscape)
    ```

=== "по умолчанию sdkconfig"

    ```ini
    CONFIG_DISPLAY_ENABLED=y
    CONFIG_DISPLAY_DRIVER_ST7789=y
    CONFIG_DISPLAY_SPI_CLK=18
    CONFIG_DISPLAY_SPI_MOSI=17
    CONFIG_DISPLAY_SPI_CS=15
    CONFIG_DISPLAY_SPI_DC=16
    CONFIG_DISPLAY_SPI_RST=21
    CONFIG_DISPLAY_BL_GPIO=38
    ```

<a id="background-image"></a>
## Фоновое изображение

При запуске драйвер загружает полноэкранный фон из `/spiffs/bg/background.bin` в
PSRAM и рисует поверх него все виджеты. При отсутствии файла экран возвращается к
сплошной черный цвет, и все по-прежнему отображается правильно.

В комплекте с прошивкой не поставляется фон — стоит один 106 КБ SPIFFS, который не подходит
наряду с веб-интерфейсом на плате размером 4 МБ, а большинство унаследованных профилей плат вообще не имеют дисплея.
Чтобы добавить один:

1. Создайте свое изображение и экспортируйте его в формате PNG. Любой размер работает — его размер можно изменить.
2. Конвертируйте его из корня проекта:
   ```bash
   python3 components/display/make_background.py <source.png> [brightness]
   ```
Яркость варьируется от `0.4` до `0.6`. Начните с `0.5`; подсветка ST7789 есть
   значительно ярче монитора.
3. Скрипт пишет `data/bg/background.bin`. Загрузите его на устройство либо
   перепрошивка SPIFFS через последовательный порт на `idf.py flash` или через WiFi:
   ```bash
   curl -X POST "http://<device-ip>/api/fs/upload?path=/spiffs/bg/background.bin" \
        --data-binary @data/bg/background.bin
   ```
Затем перезагрузитесь — новый фон загрузится при следующей загрузке.

Для фоновой загрузки нет веб-интерфейса; веб-интерфейс устройства охватывает настройку WiFi
и только конфигурация.

<a id="colour-banding"></a>
### Цветовые полосы

Панель RGB565, поэтому красный и синий имеют 32 уровня, а зеленый — 64, по сравнению с 256 каждый.
Тонкие темные градиенты демонстрируют **видимые полосы**, что является аппаратным ограничением и не является полным.
программное исправление. Яркий контраст и четкие цветовые области хорошо визуализируются. Скрипт конвертации
применяет сглаживание Флойда-Стейнберга, что немного помогает.

Если цвета получаются размытыми, перепутанными или психоделическими, то порядок байтов неправильный, а не
драйвер — см. тест цветной полосы в
[README компонента дисплея](https://github.com/serverdevel/airplay-esp32/blob/homekit-0.2.1.4/components/display/README.md).

<a id="cover-art"></a>
## Обложка

По умолчанию обложка альбома отключена, поскольку она может привести к остановке аудиоконвейера. Если у вас есть
TFT-дисплей и хотите его, см. [Настройка AirPlay](airplay-tuning.md#cover-art).

<a id="implementation-notes"></a>
## Замечания по реализации

Неочевидные требования к интеграции для ESP-IDF + LVGL 9 + `esp_lvgl_port` — вращение
порядок, соответствие ядра задачи LVGL и размещение буфера DMA — документированы вместе с
код в
[README компонента дисплея](https://github.com/serverdevel/airplay-esp32/blob/homekit-0.2.1.4/components/display/README.md).
