# OLED-дисплей

Небольшой OLED-экран может отображать воспроизводимую в данный момент дорожку: название, исполнителя, альбом, прогресс.
полоса и время воспроизведения. Длинный текст прокручивается автоматически, и при этом появляется индикатор паузы.
воспроизведение приостановлено.

Эти панели широко доступны по цене 1–2 доллара. Искать «0,96-дюймовый OLED I2C SSD1306».

<a id="supported-displays"></a>
## Поддерживаемые дисплеи

| Контроллер | Разрешение | Автобус |
| --- | --- | --- |
| SSD1306 | 128×64 | I2C или SPI |
| SH1106 | 128×64 | I2C или SPI |
| SSD1309 | 128×64 | I2C или SPI |

Панели 128×32 (SSD1306 и SH1106) также работают и переходят в компактную двухстрочную компоновку.

<a id="wiring-i2c-the-default"></a>
## Проводка (I2C, по умолчанию)

| OLED-контактный | ESP32 GPIO | Функция |
| --- | --- | --- |
| ПДД | 21 | Данные I2C |
| СКЛ | 22 | I2C часы |
| ВКК | 3,3 В | Мощность |
| GND | GND | Земля |

Адрес I2C по умолчанию — `0x3C`. Если ваша панель использует `0x3D`, измените его в разделе
**Приемник AirPlay → Конфигурация дисплея**.

<a id="enabling-the-display"></a>
## Включение отображения

Дисплей **отключен по умолчанию**.

=== "ESP-IDF"

    ```bash
    idf.py menuconfig
    # AirPlay Receiver → Display Configuration
    #   Enable "Enable OLED display"
    #   Select your driver (SSD1306, SH1106 or SSD1309)
    #   Select bus type (I2C or SPI) and set GPIO pins if needed
    ```

=== "PlatformIO"

Запустите менюконфигурацию через PlatformIO:

    ```bash
    pio run -e esp32s3 -t menuconfig
    ```

Или добавьте параметры напрямую в настройки sdkconfig по умолчанию:

    ```ini
    CONFIG_DISPLAY_ENABLED=y
    CONFIG_DISPLAY_I2C_SDA=21
    CONFIG_DISPLAY_I2C_SCL=22
    ```

<a id="options"></a>
## Параметры

| Вариант | По умолчанию | Описание |
| --- | --- | --- |
| Драйвер дисплея | SSD1306 | SSD1306, SH1106 или SSD1309 |
| Высота дисплея | 64 пикселя | 64 или 32 |
| Тип автобуса | I2C | I2C или SPI |
| I2C SDA GPIO | 21 | Линия данных, режим I2C |
| I2C SCL GPIO | 22 | Линия часов, режим I2C |
| I2C адрес | 0x3C | 7-битный адрес, 0x3C или 0x3D |
| Флип-дисплей | Нет | Повернуть выход на 180° |
| Интервал обновления | 500 мс | Как часто перерисовывается дисплей, 100–5000 мс |

Режим SPI предоставляет дополнительные настройки GPIO для CLK, MOSI, CS, DC и RST.

!!! note "Требуются подмодули"

    Для рендеринга OLED используются подмодули git `u8g2` и `u8g2-hal-esp-idf`. Клонировать с
    `--recursive` или запустите `git submodule update --init --recursive` в существующем
    checkout, иначе сборка не удастся.
