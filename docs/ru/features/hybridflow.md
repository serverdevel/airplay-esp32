# DSP HybridFlow (TAS57xx)

Некоторые усилители TAS57xx имеют небольшое ядро DSP (TI называет его miniDSP), которое может
сигнальная цепь перед выходным каскадом. TI поставляет эти цепочки как процесс **HybridFlow**.
течет, и прошивка может загрузить его, настроить его в реальном времени с веб-страницы и сохранить настройку.
через перезагрузки.

Страница настройки находится по адресу `http://<device-ip>/hf` или **HybridFlow Tuning** в настройках.
страница. Он появляется только в сборке с `CONFIG_DAC_TAS57XX`.

<a id="the-two-flows"></a>
## Два потока

Оба стереовхода, два выхода, и только один из них может быть резидентным одновременно — они отображают
коэффициент ОЗУ по-разному.

=== "HybridFlow 1 — полный диапазон"

Обычная стереоцепочка, одинаковая обработка на обоих каналах:

    ```
    In → Biquad EQ (10 bands) → PBE → DBE → Compander → Volume → Smooth clip → Out
    ```

PBE — психоакустический бас, DBE — динамический бас, компандер — трехполосный.
    компрессор/экспандер. Настраивайтесь в таком порядке: сначала максимальная громкость, затем эквалайзер для базовой линии.
    ответ, затем компандер и плавный клиппер для ограничения мощности, затем DBE и PBE.

=== "HybridFlow 3 — двухполосный"

Два выхода усилителя перестают быть левым и правым. Входные данные подаются двумя способами
    параллельно, каждая с кроссовером и четырьмя полосами эквалайзера, и они рекомбинируются в
    общий компандер и клиппер:

    ```
    In ─┬→ Low way  → PBE → DBE ─┬→ Compander → Smooth clip → Volume → Out
        └→ High way → Delay ─────┘
    ```

Канал А управляет низкочастотным динамиком, канал Б — твитером. Задержка на шоссе выравнивает его
    акустический центр с низким проходом. Только низкий уровень имеет усилители басов.

=== "Нет обработки"

Flow `0` удаляет рабочий поток и возвращает воспроизведение в стерео ROM партии.
    программа: простая левая и правая с цифровой громкостью, без кроссовера, эквалайзера или динамики. Это
    — это единственная настройка, доступная для детали без пригодного для использования HybridFlow, и она отбрасывает
    ничего, кроме файла потока — сохраненные настройки остаются.

!!! danger "Переключение на двухканальное усиление меняет то, что видят ваши динамики"

    Твитер, подключенный к выходу, который внезапно начинает воспроизводить полнодиапазонные басы, не выдержит этого.
    Прошивка снижает громкость до минимума при любом изменении потока и оставляет ее на этом уровне, поэтому
    проверьте проводку, прежде чем включать ее обратно.

<a id="base-flows-and-sample-rates"></a>
## Базовые потоки и частоты дискретизации

Изображения потока находятся в SPIFFS под `/spiffs/hf/`. В хранилище отслеживаются четыре нетронутых
базовые изображения:

```
base-hf1-44100.bin   base-hf1-48000.bin
base-hf3-44100.bin   base-hf3-48000.bin
```

Коэффициенты рассчитаны на одну частоту дискретизации, поэтому каждый поток имеет частоту 44,1 кГц и 48 кГц.
близнец. Драйвер выбирает тот, который соответствует текущей скорости вывода, и переключается на другой, если
скорость меняется, воспроизводя на нее сохраненную настройку. Базы копируются в рабочую
поток, а не воспроизводится напрямую, поэтому коммит никогда не сможет их записать.

Выбор потока перезаписывает рабочий процесс и повторно загружает его:

```bash
curl -X POST "http://<device-ip>/api/hf/flow" \
     -H 'Content-Type: application/json' -d '{"flow":3}'
```

<a id="apply-commit-and-revert"></a>
## Применить, зафиксировать и отменить

Страница настройки различает три вещи, и разница имеет значение:

| Действие | Что он делает | выживает |
| --- | --- | --- |
| **Применить** | Записывает настройку в ОЗУ коэффициентов DSP, чтобы вы могли ее услышать | Воспроизведение, режим ожидания, передача управления Bluetooth |
| **Принять** | Записывает настройку в образ потока и записывает ее в SPIFFS | Перезагрузки и перезагрузки потока |
| **Вернуть** | Перезагружает зафиксированный поток из SPIFFS, прекращая прослушивание | — |

Прослушивание бесплатное: во прошивку ничего не пишется до коммита и всегда перезагрузка
возвращает последнюю зафиксированную настройку.

Общая громкость и настройки каждого канала расположены *вне* этого. Они являются собственностью части
регистры, те же, что и на дисках AirPlay, поэтому применяются сразу и сохраняются
отдельно — они работают даже при отсутствии загруженного потока. Тонкая регулировка громкости является исключением: она
это усиление внутри потока, поэтому оно относится к настройке и только Commit сохраняет его.

<a id="where-the-files-live"></a>
## Где живут файлы

| Путь | Содержание |
| --- | --- |
| `/spiffs/hf/base-hf<n>-<rate>.bin` | Нетронутый базовый поток, никогда не записываемый |
| `/spiffs/hf/tas57xx_fw.bin` | Рабочий процесс, переписанный Commit |
| `/spiffs/hf/hf1.cfg` | Совершенная настройка HF1 |
| `/spiffs/hf/hf3.cfg` | Совершенная настройка HF3 |

`.cfg` записывает параметры, которые изображение потока не может — фильтровать формы, типы полос — поэтому
Страница может отображать пиковый фильтр как пиковый фильтр, а не как шесть необработанных коэффициентов. Это
ему доверяют только до тех пор, пока он воспроизводит поток байт за байтом; если поток был
заменено, поскольку поток побеждает, и страница говорит об этом.

Загрузка потока вручную по-прежнему работает, если у вас есть экспорт консоли PurePath:

```bash
curl -X POST "http://<device-ip>/api/fs/upload?path=/spiffs/hf/tas57xx_fw.bin" \
     --data-binary @my_flow.bin
```

Остальную часть файлового API см. в [Файловая система SPIFFS](../reference/spiffs.md).

<a id="troubleshooting"></a>
## Поиск неисправностей

**На странице указано «Нет обработки», а переключатель потока пуст.** Нет базового изображения для
текущая частота дискретизации присутствует. Проверьте `curl "http://<device-ip>/api/fs/list?dir=/spiffs/hf"`
и перепрошить SPIFFS на `pio run -e <env> -t uploadfs`, если он пуст.

**Страница загружается, но все элементы управления отключены.** В этой части нет пригодного для использования miniDSP или
поток не прошел проверку. Журнал загрузки сообщает об обоих.

**Настройка перестала соответствовать после обновления прошивки.** SPIFFS не затрагивается приложением OTA.
обновление, поэтому старый `.cfg` все еще там. Если изображение потока изменилось, драйвер возвращается назад.
для чтения настройки из самого потока и регистрации предупреждения.
