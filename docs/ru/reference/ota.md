# Обновления OTA

Как только устройство окажется в вашей сети, вы сможете обновить его прошивку через WiFi без
отключая что-либо. USB нужен только для самой первой прошивки.

1. Получите новую прошивку — либо соберите ее (`pio run -e <env>` или `idf.py build`), либо
   загрузите `.bin` с сайта
   [страница релизов](https://github.com/serverdevel/airplay-esp32/releases/latest).
2. Откройте веб-интерфейс устройства. Найдите его IP-адрес в списке подключенных клиентов вашего маршрутизатора.
3. Используйте страницу загрузки прошивки, чтобы прошить новую версию.

Устройство автоматически перезагрузится с новой прошивкой. Настройки, хранящиеся в NVS — устройство
имя, учетные данные WiFi, громкость, эквалайзер — пережить обновление.

!!! warning "OTA не может изменить таблицу разделов"

    Если вы обновляете прошивку, созданную до раздела SPIFFS `storage`
    существовало, первая прошивка должна происходить через последовательный порт, поскольку структура разделов
    сам меняется. См. [Файловая система SPIFFS](spiffs.md#flashing-the-image).

<a id="updating-files-without-reflashing"></a>
## Обновление файлов без перепрошивки

Веб-страницы, фоновое изображение ST7789 и программы гибридного потока TAS57xx живут на SPIFFS и
можно заменить индивидуально по HTTP, не трогая прошивку:

```bash
curl -X POST "http://<device-ip>/api/fs/upload?path=/spiffs/www/index.html" \
     --data-binary @data/www/index.html
```

Полный набор конечных точек см. в [API управления файлами](spiffs.md#file-management-api).
