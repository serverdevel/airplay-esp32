# ESP32 AirPlay enclosure

Printable enclosure parts for the ESP32-S3 and PCM5102A assembly described in
the project's [assembly guide](../../getting-started/assembly.md).

| File | Purpose |
| --- | --- |
| `esp32-airplay-enclosure.stl` | Main enclosure body |
| `esp32-airplay-rear-cover-standard.stl` | Rear cover with 0.30 mm guide clearance; recommended |
| `esp32-airplay-rear-cover-tight.stl` | Rear cover with 0.20 mm guide clearance |

Both rear covers have a 35 × 22 mm outer face matching the enclosure. Their
retaining guides are shaped around the enclosure's asymmetric internal rails.
The meshes are closed two-manifold solids and were checked in the installed
position for intersections.

Print a rear cover with the flat exterior face on the build plate and the
guides facing upward. A 0.4 mm nozzle, 0.2 mm layer height and three perimeters
are suitable starting settings. The cover does not require supports.
