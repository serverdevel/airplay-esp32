# Корпус AirPlay-приёмника на ESP32

Детали корпуса для 3D-печати предназначены для сборки на ESP32-S3 и PCM5102A,
описанной в [руководстве по сборке](../../ru/getting-started/assembly.md).

| Файл | Назначение |
| --- | --- |
| `esp32-airplay-enclosure.stl` | Основная часть корпуса |
| `esp32-airplay-rear-cover-standard.stl` | Задняя крышка с зазором направляющих 0,30 мм; рекомендуемый вариант |
| `esp32-airplay-rear-cover-tight.stl` | Задняя крышка с зазором направляющих 0,20 мм |

Внешняя поверхность обеих крышек имеет размер 35 × 22 мм и совпадает с корпусом.
Форма удерживающих направляющих учитывает асимметричные внутренние рельсы корпуса.
Сетки представляют собой замкнутые двухмногообразные тела и проверены на пересечения
в установленном положении.

Печатайте крышку плоской внешней стороной на столе, направляющими вверх. В качестве
начальных параметров подойдут сопло 0,4 мм, слой 0,2 мм и три периметра. Поддержки
для крышки не требуются.
